# 複数タブ開くツール（multi-url-opener.html）

複数のURLや検索語を一度に入力し、それぞれを **新しいタブでまとめて開く** ためのツールです。
URLを1件ずつコピー＆ペーストしてタブを開く作業や、同じ検索エンジンで何度も検索する作業を省けます。

---

## 特徴

- HTMLファイル1つで動作します（インストール・管理者権限・拡張機能は不要）
- 2つの機能をタブで切り替えて使います
  - **URLを開く**：入力したURLを、それぞれ新しいタブで開きます
  - **検索する**：入力した検索語を、選んだ検索エンジンでそれぞれ新しいタブで検索します

---

## 動作環境

| 項目 | 内容 |
|------|------|
| ブラウザ | Google Chrome / Microsoft Edge など |
| 実行方法 | ローカルに保存したHTMLファイルをブラウザで開く |

---

## 事前準備（ポップアップの許可）

このツールは、1回のクリックで複数のタブを開きます。ブラウザの初期設定では、2つ目以降のタブが **ポップアップブロックで止められる** ことがあります。

1. ツールを開いて、一度実行します
2. アドレスバーの右端にポップアップブロックのアイコンが出たら、クリックします
3. 「ポップアップとリダイレクトを常に許可する」を選んで「完了」を押します
4. もう一度実行します

> **確認方法**：3件入力したのに1つしかタブが開かない場合は、ポップアップがブロックされています。

---

## 使い方

### 「URLを開く」タブ

1. 開きたいURLを1行に1つずつ入力します
   ```
   https://www.google.com
   https://www.yahoo.co.jp
   https://www.bing.com
   ```
2. 「URLを開く」ボタンを押します
3. 入力した順に、それぞれ新しいタブで開きます

- 空の行は無視します
- `http://` / `https://` を省略した場合は、自動で **`https://`** を付けます
  - httpでしか接続できないURL（社内機器の管理画面など）は、`http://` から入力してください

### 「検索する」タブ

1. 「検索エンジン」で、使う検索エンジンを選びます

   | 選択肢 | 検索に使うURL |
   |--------|---------------|
   | Google | `https://www.google.com/search?q=` |
   | Bing | `https://www.bing.com/search?q=` |
   | Yahoo! JAPAN | `https://search.yahoo.co.jp/search?p=` |
   | DuckDuckGo | `https://duckduckgo.com/?q=` |

2. 検索したい文字列を1行に1つずつ入力します
   ```
   東京 観光
   大阪 グルメ
   京都 紅葉
   ```
3. 「検索開始」ボタンを押します
4. 検索語ごとに、検索結果が新しいタブで開きます

- 1行の中にスペースを入れると、その行は複数の語を組み合わせた1回の検索（AND検索）になります
- 日本語や記号は、自動でURL用の形式に変換します

---

## 注意事項

| 項目 | 内容 |
|------|------|
| 開くタブの数 | 入力した件数分のタブを一度に開きます。件数が多いと、ブラウザやPCの負荷が大きくなります。スペックの低い環境では、件数を分けて実行してください |
| ポップアップブロック | 許可していないと、2つ目以降のタブが開きません（「事前準備」を参照） |
| 検索エンジンの制限 | 短い時間に大量に検索すると、検索エンジン側で一時的に制限（ロボット確認など）がかかることがあります |
| 機密情報 | 検索語は、検索エンジンにそのまま送られます。社内情報や機密情報は入力しないでください |
